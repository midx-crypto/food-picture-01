A steaming bowl of tonkotsu ramen made to make you hungry: creamy golden broth, noodles lifted in a swirl by wooden chopsticks, a halved soft egg with a glossy jammy yolk, glistening chashu pork, spring onions and nori, in warm golden light. The program simply copies the vendored image to /output/entry.png, byte for byte, so both runs write identical bytes with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
