A towering smash burger made to make you hungry: a glossy toasted brioche bun, melted cheddar dripping down the sides, a charred beef patty, fresh green lettuce, a red tomato slice and crinkle-cut pickles, in warm dramatic light on a dark wooden board. The program simply copies the vendored image to /output/entry.png, byte for byte, so both runs write identical bytes with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Check the copy without rewriting it:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py --verify
```
